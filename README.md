## What I'm working on

**Software Developer @ Da Vinci Board Game** — full-stack work on the management platform of a multi-branch board-game café and online store.

- **420+ merged pull requests** across the NestJS API, React admin panel, customer TV screens, QR menu and mobile app.
- **Marketplace integrations:** built n11, Idefix and Amazon FBA from scratch, plus Trendyol — orders, stock and price sync, returns and webhooks; hardened Shopify order and refund flows.
- **Tournament system:** a fixture engine with Swiss pairing, table allocation, byes and knockout brackets; registration with quotas, waitlist and e-mails; QR check-in; live standings on players' phones.
- **Real-time operations:** Socket.IO-powered QR check-in/out, "order ready" calls on TV screens, live tables, automatic menu updates when stock runs out.
- **Quality:** Jest / Vitest suites, SonarQube, Docker pipelines and an AI-assisted PR review (Gemini) running in GitHub Actions.
